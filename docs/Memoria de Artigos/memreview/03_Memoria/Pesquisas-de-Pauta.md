# Pesquisas de pauta

Memória paralela das pesquisas de estratégia de conteúdo: o que foi buscado, de onde veio e o que se concluiu. A pesquisa mais nova fica no topo.

- **O estoque continua na [[Fila-de-Pautas]].** Cada ideia daqui que vira pauta entra lá, com código e data. Este arquivo guarda a evidência: autocompletar, Trends, concorrentes, catálogo e decisões.
- **Autocompletar mostra presença, não volume.** O Trends dá índice relativo. Nenhum dos dois substitui o GSC.
- **Data de cada leitura sempre junto do dado.** Preço e campanha vencem. Antes de virar artigo, tudo é relido.
