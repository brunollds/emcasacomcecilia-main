## 6. Esqueleto (H2)

Intro: o removedor é um spray da Skelt para tirar o autobronzeador de quem já aplicou há alguns dias. A marca não promete resultado de pele; este texto só descreve o uso e o preço.

1. **Resposta rápida:** espere pelo menos 3 dias, aplique o spray na pele seca, deixe 3 minutos, retire com toalha ou esponja molhada com água morna, enxágue. Preço: R$ 69,90 (140 ml).
2. **Passo a passo (ficha):** agitar; aplicar na pele seca; manter no mínimo 3 minutos; remover com toalha ou esponja molhada com água morna; tirar o excesso com água.
3. **Quando usar e quando esperar:** a ficha pede pelo menos 3 dias depois da aplicação. Antes disso, o removedor não é indicado pela marca.
4. **Preço e tamanho:** 140 ml a R$ 69,90 (R$ 0,50 por ml). Conta com a luva (R$ 34,90) só se o leitor perguntar se precisa dela para remover (não precisa; a luva é para aplicar).
5. **E sem removedor?** Só entra se a ficha confirmar (ver pendentes). Sem confirmação, o texto não sugere outro método.
