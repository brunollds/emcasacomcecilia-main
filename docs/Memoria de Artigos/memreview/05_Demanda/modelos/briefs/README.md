# Modelos de brief

Cada sessão de uma rodada recebe um brief montado de três partes, nesta ordem:

1. `COMUM.md` (regras de toda sessão);
2. o modelo do papel (`rotina-site.md`, `etapa-2-catalogo.md`, `etapa-3-pesquisa.md`, `etapa-4-dados.md`,
   `etapa-5-analise.md` ou `revisao.md`);
3. o `parceiros/<slug>/briefs/BRIEF-PARCEIRO.md` da rodada (modelo em `modelos/BRIEF-PARCEIRO.md`).

A coordenação junta as três, troca os `<marcadores>` e grava a instância em `parceiros/<slug>/briefs/<papel>.md` **antes**
de abrir a sessão; a mensagem de abertura é o conteúdo desse arquivo. O que for pedido depois, por mensagem, entra no
`parceiros/<slug>/decisoes.md` (`PROGRAMA.md`, seção 2.2).

Mudança num modelo vale para a rodada seguinte; instância já enviada não é reescrita.
